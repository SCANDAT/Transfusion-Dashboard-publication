# Dashboard fonts

| Typeface | Use | Local file |
| --- | --- | --- |
| Source Serif 4 | Body text, controls, chart labels and scientific symbols | `source-serif-4.woff2` |
| Libre Caslon Text | Headings | `libre-caslon-text.woff2` |
| Montserrat Bold | SCANDAT wordmark | `montserrat-wordmark.woff2` |

The dashboard serves all three typefaces locally. SVG figure downloads embed the first two fonts and their licence notices. The Montserrat file contains the characters used by the wordmark. Each font is distributed under the SIL Open Font License 1.1, with its copyright and licence notice alongside the WOFF2 file.

- [Source Serif 4](https://github.com/google/fonts/tree/main/ofl/sourceserif4)
- [Libre Caslon Text](https://github.com/google/fonts/tree/main/ofl/librecaslontext)
- [Montserrat](https://github.com/google/fonts/tree/main/ofl/montserrat) and the [SCANDAT wordmark subset](https://fonts.googleapis.com/css2?family=Montserrat:wght@700&display=swap&text=SCANDAT)
